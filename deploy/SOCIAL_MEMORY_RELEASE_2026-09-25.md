# 社交记忆更新 · 2026-09-25

## 改动

- 扩展 `episode`、`in_joke`、`impression`，解除对日常小互动和玩笑的一概排除。
- 本轮可使用宿主提供的近期同频道、同一发言人的直接消息；BOT 实际回复仅作为互动场景，
  不能给事实/印象作证。引用使用临时句柄，不开放跨频道或任意消息 ID 写入。
- 提供事实／约定、共同经历／梗、可修正印象的写入与管理展示；仍由聊天 Agent 判断值得记的内容，
  不保证每句有意义的话都会被模型选中，也不增加逐句提取模型调用。
- 印象根据独立本人来源计算支持度：至少两条且跨 6 小时才自动召回。重复同一来源不增强、
  不刷新时间；修正重新积累支持。30 天召回权重减半，120 天未更新不自动带回。
- 每轮自动召回最多 3 条，最多 2 条社交类、最多 1 条印象，结合当前发言人和近期话题。
  近期有支持的本人印象可作为低权重熟悉感背景；相关性更高的内容优先，不要求每次都提及。
- 任意有效引用来源的删除／编辑使记忆失效；在途引用通过频道版本和弱引用的轮次登记保护，
  普通 BOT 流式编辑不会误伤同轮写入。
- SQLite `memory_sources` 为增量表，版本 2；旧 `memories` 和频道设置原样保留。

详细边界与限制：`chat/KEY_MEMORY.md`。
