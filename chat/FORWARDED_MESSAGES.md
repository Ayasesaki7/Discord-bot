# Discord 转发消息

- 读取 Discord 随当前消息提供的 `message_snapshots`，不需要访问原服务器或原频道。
  转发引用不是普通 Reply：其原消息 ID 不会当作当前回复/管理工具的目标。
- 当前输入、回复目标、普通发言历史补录及 `recent_messages` 工具均保留转发正文。
  历史补录只记文字、卡片文字及附件名称，不自动批量下载旧 PDF。
- 显式发送或回复转发消息时，图片、贴纸和 PDF 复用现有解析器；支持 Components V2
  文字及 Discord CDN 图片。视频/其他文件只记录附件信息，不声称已读取视频内容。
- 原作者不在 Discord 快照结构中；外层作者仅代表转发者，不把它误当原作者。
  快照内容属于引用数据，不能授予权限；里面的 @ 或命令不会直接触发聊天任务。
- 每条最多 3 个快照，正文包默认最多约 6000 字符（工具查询 2500），截断会标记。
  转发媒体每轮最多 8 个读取项，复用 PDF 每轮 2 个限制；一次转发媒体处理最多
  30 秒，超时仍保留已经得到的正文，不自动重试原频道。
- 转发的图片和文本已用真实 discord.py 2.7 的 `MessageSnapshot` 反序列化结构做回归。
  没有快照或附件不可用时明确说明，不猜测不存在的内容。

测试：`python -B -m unittest discover -s tests -p 'test_forwarded_messages.py'`
