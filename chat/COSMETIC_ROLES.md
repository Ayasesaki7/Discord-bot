# 幻化身份组

所有成员都可通过 Agent 的 `cosmetic_roles` 工具管理个人幻化外观，不需要 Discord 管理员权限。普通聊天、引文或仅提到“幻化”不触发宿主强制操作，具体动作由 Agent 判断。

## 启用条件

- 当前服务器必须有唯一的 `---  幻化区开始 ---` 和 `---  幻化区结束 ---` 身份组，开始在结束上方；空白数量可不同。
- 仅两个标记**之间**的身份组可操作。缺少、重名、顺序错误或移出范围时拒绝操作，不自动建立边界。
- BOT 须有管理身份组权限，且最高身份组在开始标记之上。
- 身份组必须无额外权限、无频道权限覆盖、非集成管理身份组。标记、特权资格身份组不可领取、编辑或删除。

## 默认规则

普通成员每个服务器最多 2 个；持有本服务器唯一、区外的 `幻化权区` 身份组最多 20 个。全区最多 100 个（含旧身份组），创建间隔 30 秒。配置按服务器独立保存。

创建默认私有，并给创建者佩戴。创建者可修改名称、纯色／渐变／全息颜色、图标、公开状态，或删除自己的身份组。高级颜色和图标受 Discord 服务器功能限制。

公开身份组可被其他成员给**自己**佩戴或取下，不能代他人操作；修改和删除始终要求登记归属。删除使用原有猫爪确认，确认后重新检查身份、边界和权限。改为私有不自动移除之前已佩戴的成员。

区内未登记的旧身份组默认公开佩戴：所有人可给自己佩戴／取下，**无需登记主人**。旧组不会计入任何人的创建额度，也不允许普通成员改名、改色或删除。权限、边界和频道授权检查仍然生效；失败创建留下的 pending 登记不属于此例外。

例：`@萝卜子 创建一个叫晚霞的粉紫渐变幻化身份组`；`把我的晚霞改成蓝绿色并公开领取`；`给我戴上晚霞`；`列出我的幻化身份组`。

工具的 `list/mine` 支持 `query` 按名称检索，以及 `offset/limit` 分页（默认 12 条，最多 25 条）；结果给出 `hasMore/nextOffset`，保证返回完整 JSON，不靠截断长列表省略身份组。

## 管理命令

- `/幻化设置`：开发者／本服服主／管理员查看配置；带“普通额度、特权额度、区内总量、特权身份组”参数则保存。特权额度上限 50，不提供无限创建。
- `/幻化归属 身份组:… 归属成员:… 公开领取:…`：可选的管理入口，仅当管理者有意将旧身份组交给指定成员管理时使用；佩戴旧组不需要此操作。不会自动推断主人，不覆盖已有归属，不修改原权限或成员佩戴状态。管理员登记旧组可以超过个人额度，但其后不能继续创建直到腾出名额。

归属使用服务器 ID、身份组 ID 和成员 ID，所有长 ID 以字符串传输。同名、跨服和过期引用不能冒领。数据保存在 `config/agent/cosmetic_roles.sqlite3`，重启不会丢失；部署与备份请保留该文件。

每服创建串行化。Discord 创建接口不支持指定位置，因此工具在创建后立即发出移动请求，将新组放到结束标记上方；中间不再插入全频道列表查询。移动响应确认位置、边界和权限合格后，才登记完成、自动佩戴并报告成功。

频道权限优先读取已连接且完整的 Discord Gateway 缓存，频道权限变更仍会实时生效；离线／未连接时才使用 REST。请求最多等待 45 秒，失败后按接口冷却，日志标明具体请求、HTTP 状态和错误类型，不再混淆为边界不合格。

放置失败或取消保留 `pending` 记录，不继续发送回滚请求。使用 `mine` 查看（含暂时在区外的未完成组），然后 `resume role_ref:…` 继续放置同一组，不新建、不改变原名或颜色。同一消息的重复创建、后续消息对同名未完成组的重试会恢复原组；存在其他未完成组时先要求恢复，避免继续制造重复组。创建者可恢复自己的组；管理者修复他人的组必须指定 `equip=false`。被外部改名、赋权、改成频道授权组、移到上边界以外，或原标记被替换时拒绝自动恢复。

旧版 pending 记录可继续读取，新恢复元数据写入独立表，不改旧归属表结构。不会清空归属数据，不自动认领或删除其他组。

这是 BOT 工具的权限边界，不会撤销任何人原有的 Discord 原生权限。若 `幻化权区` 本身已有“管理身份组”，持有者仍能在 Discord 客户端按原生权限操作；是否撤销该权限须由服主另行决定。
