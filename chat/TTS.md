# 日语语音工具

普通聊天不会因为单个“说/声音/朗读”关键词自动合成。Agent 按完整语义判断：用户对 ATRI 说“说一下”“跟我说句话”
“用你的声音说”“发段语音”“朗读这句”“日语说一遍”“念给我听”等，视为想听语音；“你说的是什么意思”“他说……”、
引用、假设、能力提问和明确要求文字回复，不触发。只有 Agent 判断用户明确想听语音，且
当前主机元数据 `tts_configured=true` 时，才会调用 `send_voice`。

“说一句晚安”“说：你好”不必再包含“语音”二字。单独的祈使句“说”从前文解析要说的短句；
目标不清楚则简短澄清，不朗读整段历史。“别说了”“只用文字说一下”等否定/文字要求优先。
规则交由主 Agent 理解，没有新增逐轮分类 API 请求，也没有宿主关键词自动调用或失败重试。

工具只接收当前准备说出的短文本。它先使用当前聊天模型翻译成自然日语，然后固定调用 Fish Audio
`s2.1-pro-free` 和 ATRI 音色 `5303afc44f544728b9a45000bf632c9e`，在当前频道回复 MP3 附件；不会加入语音频道，
不会改音乐播放器，也不会把音频留在服务器上。API Key 只在服务器私有环境文件中，严禁写进源码、日志、SQLite
或聊天上下文。

Fish 官方文档说明 `s2.1-pro-free` 与 S2.1 Pro 同模型、价格为 $0，但有公平使用限制；不自动切换到收费模型。
失败或超时进入冷却；同一 Discord 消息只允许一次尝试，结果不确定也不自动重发，避免重复附件。当前实现限制
单次原文 500 字、音频不超过频道附件上限（最多 8 MiB），每天全局 300 次、单服 100 次，并限制并发/间隔。

服务器管理员可在 `/服务器设置` 里关闭本服语音。关闭、频道范围和聊天白名单都会在翻译前及发送前再次检查。
没有语音权限、上传附件权限、Fish Key、Fish 免费额度或模型返回非音频时，只返回文字错误，不把异常当成成功。

## 情绪与语气

`send_voice` 接收 `text` 和可选 `segments`。Agent 根据上下文自由描述每段情绪/表达方式，用户要求优先，
不固定情绪词表、不限制整句只能一种情绪，也没有宿主关键词匹配或额外情绪分类请求。
可以在一句话中途切换，也可以让一段同时“有些担心但努力装得勇敢、温柔地说”。未指定时自然说话。

例如（`style` 建议用简短英文自由描述，不是固定枚举）：

```json
{
  "text": "真的吗？太好了，晚安。",
  "segments": [
    {"text": "真的吗？", "style": "surprised and a little uncertain"},
    {"text": "太好了，", "style": "delighted, with a sense of relief"},
    {"text": "晚安。", "style": "tender, soft whisper"}
  ]
}
```

片段文本按顺序拼接必须完整等于 `text`；只限制请求体大小（最多 12 段、每段语气 96 字），不限制情绪种类。
所有片段由当前聊天模型在**一次请求**中结合整句翻译，保留分段顺序，整条日语共最多 700 字。
格式或片段数量不匹配则停止，不悄悄忽略语气、不自动重试。之后只调用**一次** Fish 合成，发一个 MP3。

S2.1 接受 `[happy]`、`[whispering]` 和自然语言语气提示等方括号文本标记，没有单独的 emotion API 字段。
宿主保留 Agent 的自由语气，在对应日语片段前添加提示；字幕只有正文，不添加标记。
正文中的字面方括号转换为日语引号，避免被当成额外控制标记。不会使用 S1 旧的圆括号语法或切换收费型号。
情感表现依赖 TTS 模型与音色，不保证每个短句都呈现明显差异。

官方说明：https://docs.fish.audio/developer-guide/core-features/emotions
